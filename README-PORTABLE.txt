========================================================================
                  YT Video Downloader - Portable Edition
========================================================================

Thank you for downloading YT Video Downloader Portable!

GETTING STARTED
---------------
1. Extract the contents of this ZIP archive to any folder or USB drive.
2. Double-click "YT-Video-Downloader.exe" to launch the application.
3. No installation, Python, or administrator rights required!

PORTABLE DATA STORAGE
---------------------
Because this is the Portable Edition, all your settings, downloaded
binary tools (yt-dlp, FFmpeg, etc.), and temporary files are stored
directly inside the "data" subfolder alongside the application.
No personal files or registry keys are left behind on the host computer.

FEATURES
--------
- Download single videos or full YouTube playlists in one click.
- Quality selection from standard definition up to 8K, 4K, and 1080p.
- High-speed multi-threaded downloads (up to 8 concurrent fragments).
- Audio extraction directly to MP3.
- Automatic backend tool updates.

SYSTEM REQUIREMENTS
-------------------
- Windows 10 or Windows 11 (64-bit)
- Active internet connection
